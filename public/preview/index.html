Tentang Saya

Pilot di Balik Interface

Saya perancang & pengembang antarmuka yang terobsesi pada estetika sci-fi militer: panel HUD, status sistem real-time, dan tipografi monospace yang tegas — seperti yang dirancang Nadia pada desain NERV Neon ini dan saya implementasikan persis di halaman ini.

Fokus saya adalah mengubah desain visual menjadi halaman web yang hidup: layout mengikuti desain aslinya, artwork memakai file asli dari desainer, dan elemen interaktif — termasuk model 3D EVA-01 di samping ini — dimuat sebagai aset beneran, bukan gambar tempelan.

Model 3D EVA-01 dibuat oleh Nadia (Designer) dan saya integrasikan dengan <model-viewer> — putar dan zoom langsung di halaman.
